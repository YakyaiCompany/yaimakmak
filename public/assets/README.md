# Media asset structure

- `brand/` — โลโก้และไฟล์ต้นฉบับของแบรนด์
- `company/` — ภาพบริษัท ทีมงาน โรงงาน และภาพประกอบหน้าเกี่ยวกับเรา
- `products/` — ภาพสินค้าและรายละเอียดเครื่องจักร
- `projects/` — ภาพผลงานติดตั้ง แยกโครงการได้ด้วยโฟลเดอร์ย่อย
- `articles/` — ภาพหน้าปกและภาพประกอบข่าวสาร
- `documents/` — โบรชัวร์ แคตตาล็อก Specification และ Company Profile

ใช้ชื่อไฟล์ภาษาอังกฤษตัวพิมพ์เล็ก คั่นคำด้วยเครื่องหมาย `-` เพื่อให้อ้างอิงบนเว็บไซต์และหลังบ้านได้ง่าย
